# lyfe-site

The privacy policy and support page for [Lyfe](https://github.com/kakery-fakery/lyfe), the
household chores and groceries iPhone app, served by GitHub Pages at
<https://kakery-fakery.github.io/lyfe-site/>.

Don't edit the pages here: their source is `site/` in the Lyfe repository, and
`scripts/publish-site.sh` there replaces everything in this repository except this file.
